## Ideas behind Lucinda

+ Components equal configurations and capabilities
+ Requests and assignment are based on capability

## New Pipeline for Lucinda

A new task pipeline designed for multiple agent architecture.

1. requests -> TaskWraapper: rawTask, no constraint for resource
2. rawTask -> TaskPlanner: taskPlan, resources control, agent architecture type 
3. taskPlan -> TaskCommander: task, upload tasks for system
4. task -> TaskExecutor: taskResult, deal with specific task and returns result to TaskCommander
5. taskResult -> TaskCommander: next task uploading or return taskPlanResult
6. taskPlanResult -> TaskPlanner: return rawTaskResult
7. rawTaskResult -> TaskWrapper: unwrap to response

In this general pipeline, the overall system will be able to support reAct or Plan-Execute agent arch more flexibly.
